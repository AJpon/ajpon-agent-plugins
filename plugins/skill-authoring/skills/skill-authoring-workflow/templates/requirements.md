# Requirements Contract

このテンプレートは案件ごとの要件契約を記録する。任意項目の追加は許可する。以下の必須項目の削除、
意味変更、別名化は設計の再承認対象とする。

## 必須項目

### 問題

- 何を解決したいか

### 利用者

- 誰が使うか

### 利用状況

- いつ、どこで、どのような依頼で使うか

### 成功条件

- 何をもって成功とするか

### 制約

- 時間、環境、権限、公開範囲など

### 事実

- 確認済みの情報

### 仮説

- まだ検証していない想定

### 未確定事項

- 次に確認または調査が必要な点

### 既存資産

- 再利用候補、関連スキル、関連規約

### 適用範囲

- 汎用原則 / ドメイン固有知識 / 環境差分 / エージェント依存

### 承認状態

- 目的照合: 未承認 / 承認
- 設計承認: 未承認 / 承認

## 任意項目

- メモ
- 参考リンク
- 代替案
- リスク

# Test Plan Contract

このテンプレートは案件ごとのテスト契約を記録する。任意項目の追加は許可する。以下の必須項目の削除、
意味変更、別名化は設計の再承認対象とする。

## 必須項目

### 対象挙動

- 何を検証するか

### テスト方式

- 行動 eval / 形式検査 / リンク検査 / 人によるレビュー など

### eval ケース

- 通常ケース
- 曖昧な依頼
- 境界ケース

### 合格基準

- 合格 / 不合格の判断条件

### ベースライン判断

- 新規スキルなら「スキルなし」
- 既存改修なら合意した比較対象

### 形式・リンク検査

- frontmatter、相対リンク、必須ファイルなど

### 人によるレビュー

- 機械判定で置き換えない観点

### 環境制約

- 実行できない検証や利用できないツール

### 未実施検証

- 今回見送った確認と理由

### 承認状態

- テスト承認: 未承認 / 承認

## 任意項目

- 失敗時の記録方法
- 回帰候補
- 実行コマンド
- 担当者メモ

# 既存資産と適用範囲の調査

## 目的

新規作成を前提にせず、既存スキルや既存規約の再利用可能性と適用範囲を確認する。

## 読むタイミング

目的照合が終わり、再利用・拡張・統合・新規のどれが妥当かを判断する直前。

## 調査の観点

1. **既存資産の確認**
   - リポジトリ内の既存スキル、関連テンプレート、既存規約、近い責務のファイルを調べる。
2. **比較の軸**
   - 再利用: そのまま使えるか
   - 拡張: 局所的な追加で足りるか
   - 統合: 重複を減らせるか。ただし破壊的変更は自動決定しない
   - 新規: 既存資産では責務が合わないか
3. **適用範囲の分類**
   - 汎用原則
   - ドメイン固有知識
   - 環境差分
   - エージェント実行機能への依存
4. **制約の明示**
   - 調査できなかった範囲、読めなかった資料、検証不能な前提はそのまま残す。

## 境界判断

- 複雑な新規作成または大幅改修でなければ、このワークフローを始めない。
- 既存の短いスキルの description 微修正、通常の eval、通常の配布だけなら、既存の `skill-creator`
  の担当として案内し、複雑作成向けのヒアリングや設計フェーズへ進まない。

必要なら、調査結果と適用範囲の分類を [../templates/requirements.md](../templates/requirements.md) に追記する。
